# Deployment

1. Upload repository contents to the GitHub repository root.
2. Commit to `main`.
3. Enable GitHub Pages from `main` + `/(root)`.
4. Test homepage, filters, every event page, organizer links and the 404 page.
5. Only after this smoke test should the GitHub Pages URL be embedded in Wix Harmony.

The 4-hour workflow is installed as a scheduling shell, but it does not yet scrape or publish new data.
